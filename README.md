# Список сотрудников

Веб-приложение со списком сотрудников: регистрация/вход, поиск по ФИО, фильтр по отделу, добавление сотрудника. Данные хранятся в SQLite и сохраняются после перезапуска.

> Тестовое задание. Исходный текст — в [`tasks/`](tasks/).

## Стек

- **Frontend:** React + TypeScript (Vite), обычный CSS
- **Backend:** Node.js + Express + TypeScript
- **БД:** SQLite (better-sqlite3); пароли — bcrypt-хеши, авторизация — JWT, валидация — zod

## Запуск

Требования: Node.js 20+ и npm.

```bash
npm install
npm run dev
```

- Клиент: http://localhost:5173
- API: http://localhost:3001

При первом запуске база создаётся автоматически и заполняется **5 демонстрационными сотрудниками**. Зарегистрируйте пользователя на странице входа — список откроется. Данные переживают перезапуск; для чистого старта удалите `server/data/` при остановленном сервере.

Production: `npm run build`, затем `npm start` (API) и `npm run preview -w client` (клиент). В проде задайте свой `JWT_SECRET`.

## Структура

```
client/src/   — api, components, pages, styles (токены — DESIGN.md)
server/src/   — db (схема + сид), middleware (JWT), routes (auth, employees)
tasks/        — текст тестового задания
```
