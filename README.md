# Список сотрудников

Веб-приложение со списком сотрудников: регистрация/вход, поиск по ФИО, фильтр по отделу, добавление сотрудника. Данные хранятся в SQLite и сохраняются после перезапуска.

> Тестовое задание. Исходный текст — в [`tasks/`](tasks/).

## Стек

- **Frontend:** React + TypeScript (Vite), обычный CSS
- **Backend:** Node.js + Express + TypeScript
- **База данных:** SQLite (better-sqlite3)
- **Авторизация:** email + пароль (bcrypt-хеши), JWT

## Структура

```
client/   — фронтенд (React + TS)
server/   — API (Express + TS) + SQLite
tasks/    — текст тестового задания
```

## Запуск

_Инструкция будет дополнена после реализации._

Требования: Node.js 20+.

```bash
npm install
npm run dev
```

При первом запуске база создаётся автоматически и заполняется 5 демонстрационными сотрудниками.
