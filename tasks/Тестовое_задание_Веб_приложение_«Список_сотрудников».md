**Тестовое задание: Веб-приложение «Список сотрудников»**

**Время на выполнение:** 2–3 часа работы. Срок сдачи — 1 сутки с момента получения задания.

**Формат сдачи:** ссылка на GitHub-репозиторий с исходным кодом и короткой инструкцией запуска. 

**Задача**

Создайте небольшое веб\-приложение со списком сотрудников. Для каждого сотрудника отображаются: ФИО, должность и отдел.

**Функционал:**

* Регистрация по email и паролю, вход и выход.  
* Список сотрудников доступен только после авторизации.  
* Поиск по ФИО и фильтр по отделу.  
* Добавление сотрудника через форму с проверкой обязательных полей.  
* Сохранение данных после перезапуска приложения.

**Стек:**

* Frontend: React \+ TypeScript, обычный CSS.  
* Backend: Node.js \+ Express \+ TypeScript.  
* База данных: SQLite.

**Требования:**

* Пароли должны храниться в виде хешей.  
* Доступ к API сотрудников также должен требовать авторизации.  
* Подготовьте 5 демонстрационных сотрудников.  
* Сложный дизайн, подтверждение email и восстановление пароля не требуются.

**Что нужно сдать:**

* Ссылка на GitHub-репозиторий с исходным кодом.  
* Короткая инструкция запуска (в README или отдельным файлом).  
* Указание, какую ИИ-модель вы использовали при выполнении задания (ChatGPT, Cursor, Claude, Copilot и т.д.) и для каких задач.  
* Будьте готовы объяснить своё решение и код на собеседовании.
