# AGENTS.md

Тестовое задание «Список сотрудников». Спецификация — `tasks/`, дизайн-контракт — `DESIGN.md`. Малый объём и простота важнее абстракций: не добавляй ничего сверх задания.

## Стек (фиксирован, не менять)

- client: React + TypeScript + Vite, **обычный CSS** (никаких UI-библиотек, CSS-in-JS, Tailwind)
- server: Express + TypeScript, better-sqlite3, bcrypt, JWT, zod
- npm workspaces; Node 20+

## Команды

- `npm install` — установка
- `npm run dev` — сервер (:3001) + клиент (:5173)
- `npm run build` — сборка обоих пакетов; тайпчек обязателен перед сдачей

## Правила

- TypeScript strict; `any` запрещён.
- Все цвета/отступы/радиусы — только через токены из `DESIGN.md`; инлайн-стили запрещены.
- Валидация всех входных данных на сервере (zod) + обязательные поля на клиенте.
- Пароли — только bcrypt-хеши; секреты и пароли не логировать, JWT-секрет — через env с dev-дефолтом.
- Весь `/api/employees` — за auth-middleware; SQL — только параметризованные запросы.
- БД: файл в `server/data/` (в .gitignore), создание и сид 5 сотрудников — автоматически при старте.
- Комментарии — только неочевидное «почему»; без docstring-полотен.
- Новые зависимости — только при реальной необходимости.
